# infosite — особистий кабінет користувача

Статичний сайт поверх JSON API бота. Жодної логіки торгівлі і жодних кнопок
керування ботом — користувач змінює лише СВІЙ список монет.

## Що лежить у цій теці (це і є все, що йде на хостинг)

```
infosite/
├── index.html    # сторінка
├── style.css     # стилі
├── app.js        # логіка: опитує API бота й малює таблиці
├── config.js     # ⚙️ єдине, що треба налаштувати: адреса бота
└── README.md     # ця інструкція (на хостинг не обов'язкова)
```

## Налаштування

Відредагуй **`config.js`**:

```js
window.INFOSITE_CONFIG = {
  BOT_API_BASE: "https://адреса-твого-бота",  // де відповідає API бота
  REFRESH_MS: 5000,                            // частота оновлення
};
```

- Якщо сайт віддається **тим самим сервером**, що й бот — лиши `BOT_API_BASE: ""`.
- Якщо бот на **окремому** хості — встав його повний URL.

## Деплой

Це звичайні статичні файли — підійде будь-який статичний хостинг
(Netlify, Vercel, GitHub Pages, Render Static Site, nginx). Просто поклади
вміст теки `infosite/` у корінь сайту.

Локальна перевірка:
```bash
cd infosite
python -m http.server 8080
# відкрий http://127.0.0.1:8080
```

## CORS

CORS для read-only `GET /api/*` **вже увімкнено на боці бота** (заголовок
`Access-Control-Allow-Origin: *` лише для безпечних GET/HEAD/OPTIONS). Тож сайт
можна тримати й на окремому домені. Якщо сайт віддає сам бот — лиши
`BOT_API_BASE: ""`, тоді запити йдуть на той самий домен.

## Що показує

Особистий кабінет користувача (вхід через бота):
- **⭐ Мій WATCHLIST** — свій список до 20 монет (зберігається в БД бота на
  акаунт): назва, ціна, зміна за ~24 год. Додати можна будь-яку USDT-монету;
  монети, яких немає в боті (🛰), сайт рахує окремо.
- **Графік** обраної монети: CHoCH/BOS, Order Blocks, Volumized OB, лінія POC;
  у шапці — Premium/Discount і POC, вибір TF графіка (1m…1D) і TF для OB / VOB
  (зберігається на акаунт).
- 🔔 стан Telegram.

API: `/api/me`, `/api/me/watchlist` (GET/POST — лише свій акаунт),
`/api/info/universe`, `/api/info/rows`, `/api/info/coin`, `/api/me/notify`,
`/api/me/logout` (вихід: відкликає всі токени сайту, далі `/logout?next=info`).
Сервер віддає готові дані зі спільного кешу — сторінка біржу не смикає.
